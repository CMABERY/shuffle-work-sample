# Colton Mabery — work sample

Open `index.html` in a browser and keep the folder together. The page links to
an interactive limit study and request-history analyzer. The tools also work
offline. Imported request data stays in the browser; no backend or account
connection is included. Serve this static folder over HTTPS if hosting it.

The limit study uses simulated sessions. The request walkthrough is synthetic.
The historical Dice checks are aggregate findings from a separate account
analysis, with explicit limitations. The proposed promotion project is future
work. These distinctions are part of the evidence.

`MANIFEST.json` identifies every distributed file and the copied study artifacts.
The preserved `work/limit-study/BUILD.json` belongs to the original explorer
build; the public package has its own manifest. Method documents describe the
selected evidence. This folder contains no source account exports or databases.
